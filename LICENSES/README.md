# Licensing

This repository is an umbrella project containing components with different dependencies and potentially different licensing requirements.

## No blanket repository licence

The repository root intentionally does not apply one blanket licence to every file and future component. Check the licence or notice inside the component you intend to use.

## Maschine EQ Unofficial Remake

The JUCE-based `plugins/MaschineEQ` component is intended to be distributed under **GNU AGPL-3.0-only** when JUCE is used under its open-source licence.

JUCE's framework modules are currently dual-licensed under AGPLv3 or the commercial JUCE licence. A developer using a commercial JUCE licence should assess their own licensing obligations independently.

See:

- `plugins/MaschineEQ/LICENSE`
- `plugins/MaschineEQ/THIRD_PARTY_NOTICES.md`

## Future converter components

Non-JUCE converter components may use a different licence where appropriate. Their directories should contain an explicit licence or notice before public release.

This file is project documentation, not legal advice.
